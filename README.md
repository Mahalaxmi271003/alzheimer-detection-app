# 🧠 Alzheimer Risk Prediction System

An AI-powered machine learning application that estimates Alzheimer's-related cognitive risk using demographic, cognitive-assessment, behavioral, and family-history features.

> ⚠️ **Educational/Research Prototype — Not a Medical Diagnosis**

## 🚀 Live Demo

👉 **[Open the Live Alzheimer Risk Prediction App](https://alzheimer-detection-app-cmzyehbxwaucfg36op5msp.streamlit.app/)**

## 📌 Overview

The Alzheimer Risk Prediction System is an end-to-end machine learning prototype designed to demonstrate how structured patient assessment data can be processed and analyzed to estimate a cognitive risk category.

The system combines:

- 📊 Data preprocessing
- 🤖 Machine learning classification
- 🎯 Risk scoring
- 📈 Model evaluation
- 🧪 Automated testing
- 🌐 Interactive Streamlit dashboard

Users can enter assessment information through the web interface and receive an estimated risk category.

## 🚀 Key Features

- 🧠 Machine-learning-based risk prediction
- 🌲 Random Forest classification model
- 📊 Model accuracy evaluation
- 👤 Interactive patient assessment interface
- 🧩 Cognitive and behavioral feature analysis
- ⚙️ Modular machine learning pipeline
- 🧪 Automated model testing
- 🌐 Streamlit-based interactive dashboard
